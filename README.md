## 📖 Overview

TechNova is a modern workplace collaboration platform designed to improve productivity, streamline communication, and empower organizations through Human-AI collaboration.

The platform leverages Artificial Intelligence to generate insights, recommendations, and automation while ensuring that critical decisions remain under human control through structured approval workflows.

---

## 🎯 Problem Statement

Organizations often struggle with:

- Fragmented communication channels
- Inefficient task prioritization
- Delayed approvals and decision-making
- Lack of visibility into productivity metrics
- Information overload across teams
- Poor workload distribution

TechNova addresses these challenges by integrating AI-driven intelligence with collaborative human workflows.

## 🔄 Human-in-the-Loop Workflow

TechNova follows a Human + AI collaboration model.

```text

        ↓
Human Review
        ↓
Approve / Reject / Modify
        ↓
Execution
```

This ensures transparency, accountability, and trust in AI-assisted decisions.

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/MonaliPawar26/TechNova.git
cd TechNova
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend will run at:

```bash
http://localhost:3000
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

Backend will run at:

```bash
http://localhost:5000
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

GEMINI_API_KEY=your_gemini_api_key

FIREBASE_PROJECT_ID=your_project_id

FIREBASE_CLIENT_EMAIL=your_client_email

FIREBASE_PRIVATE_KEY=your_private_key
```
